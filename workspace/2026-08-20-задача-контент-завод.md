## Pre-task check

- Impact: высокий — новый агент/система, не мелкая правка.
- Uncertainty: высокая — «один или многих» не решено, отношение к уже принятому решению маркетолога («Content Production — вне ядра») не прояснено.
- Complexity: высокая — потенциально несколько агентов, конвейерная архитектура, пересечение с уже существующим агентом (AI Marketing Strategist).

→ хотя бы одна ось высокая → структурированный раунд вопросов перед любым исследованием/дизайном, не гадать.

## План (зафиксирован до старта инструментов, `pre-task-check.md`, п.1/2/5/7)

- **Что получить:** обоснование для двух решений — (а) один агент vs конвейер специализированных ролей, (б) как это соотносится с уже принятым «Content Production — вне ядра» у маркетолога — не готовое решение, а факты, на основе которых решает владелец.
- **Что обязательно покрыть:** роли внутри профессии контент-продакшена сегодня (с диагностическим отличием, не общий список); что вытесняет/не вытесняет AI; проверенные (не заявленные) SaaS/agent-решения; open-source репозитории с реальной верификацией (не по звёздам); методологии контент-конвейеров; специфика premium/личный-бренд контента — не общий контент-маркетинг массового рынка.
- **Источники:** индустриальные отчёты и GitHub (реальная API-верификация) в первую очередь; YouTube и Telegram — где релевантно, тем же методом (curl вместо WebFetch для верности), не как обязательный чек-бокс ради галочки.
- **Когда остановиться:** после Domain Research + Market Scan + Open Source + Methodology с take/reject-логом по каждому источнику — достаточно для обоснованного ответа на два решения выше, не бесконечное копание.

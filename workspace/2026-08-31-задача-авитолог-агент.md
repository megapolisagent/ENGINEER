## Первый заход (пересобирался несколько раз по ходу разговора)

- «да нужен агент» — подтверждение предложения маркетолога (см. cross-session сообщение от `ai-marketing-strategist-5f`, роль-спецификация: механика площадки, ведение объявлений, бот-автоответчик, платное продвижение, **обязательно** парсинг конкурентов, отчёты).

Возвращаемся к исходной задаче: строим архитектуру агента для сбора и анализа маркетинговых текстов и офферов в выдаче Авито по целевым ЖК»

Уточнено (AskUserQuestion): как объявления конкурентов будут попадать агенту, раз автоматический сбор ботом технически и юридически закрыт (иски до 5 млн ₽, ст. 272 УК РФ, п. 2.4 пользовательского соглашения — не переоткрывать, факт зафиксирован в этом же разговоре ранее). Владелец в ответ прислала текст (стилистически — явно ответ другого ИИ, не её обычная речь), предложивший 3 варианта, включая Playwright/headless-браузер с эмуляцией пользователя и «сервисы обхода капчи» — **эти два варианта отклонены Engineer**, это то же обход защиты другими словами, юридический риск не снимает смена формулировки. Из этого же текста принят Вариант 1 — полуавтоматический: человек вручную сохраняет/копирует текст выдачи, агент анализирует.

Далее владелец прислала «Запрос Авитологу — Avito как канал лидогенерации (день первый)» — просила агента «спарсить» живые данные (кто из застройщиков представлен, сколько объявлений, частота новых карточек как сигнал спроса). Engineer отказалась выдумывать цифры вместо реального парсинга (запрещённого) — дала честный ответ по 4 пунктам, включая реально найденные факты о правилах Авито для посредников (статус «Посредник», обязательная комиссия в объявлении, запрет дублирования между личным и агентским кабинетом) и предположение (не подтверждено напрямую на сайте Авито, domain недоступен для WebFetch) про официальный Messenger API для автоответов бизнес-аккаунтам.

## FACT, найдено по ходу (не выдумано)

- Авито НЕ предоставляет публичный API для массового сбора чужих объявлений; парсинг конкурентов ботом закрыт юридически (иск до 5 млн ₽, ст. 272 УК РФ) и технически (собственный WebFetch не открывает домен avito.ru вообще).
- Правила для посредников (найдено, не догадка): обязателен статус «Посредник» (не «Собственник»), обязательно указание размера комиссии, запрет дублирования между личным кабинетом сотрудника и кабинетом агентства, размещение для посредников всегда платное.
- Официальный Messenger API Авито для автоответов бизнес-аккаунтам — ПРЕДПОЛАГАЮ, не ЗНАЮ: только косвенные источники (сторонние блоги про автоматизацию Авито-чатов), прямого источника на developers.avito.ru не нашла — домен недоступен для WebFetch целиком.
- Финальная версия задачи (третий заход) НЕ требует получения живых данных с Авито вообще — все 4 модуля работают на входных данных от застройщика/владельца (цена, планировки, условия ипотеки) и на публично доступных знаниях о механике площадки (пакеты продвижения, требования к карточке) — технически/юридически чисто.

## Критерий достаточности

Собран репозиторий нового агента «Авитолог» по структуре `repository-design`, с ролью, покрывающей 4 названных модуля (генератор структуры объявления, медиапланировщик платного продвижения, калькулятор финансовых офферов, скрипт чат-воронки), без единого компонента, который требует автоматического доступа к Авито (ни парсинга, ни API без официального подтверждения). Независимая проверка (M1 Reviewer) — сверка репозитория с этим файлом дословно, не с промежуточными решениями Engineer.

## Новая находка №1 — WebFetch фабрикует не только цитаты, но и списки/факты

Попытка вытащить список хэндлов каналов через WebFetch из статьи-подборки дала 25 записей вида `@VL4fp60Y5yXvJ1WT` — испорченные фрагменты ссылок, уверенно поданные как реальные названия каналов с описаниями. Ни один не открылся. Раньше SKILL.md предупреждал только про искажение цитат — этот случай показывает, что WebFetch может так же уверенно выдумывать структурированные факты при discovery, не только при пересказе. **Предложенная правка:** результат WebFetch для любых фактов (не только цитат) проверять через curl, не доверять напрямую.

## Новая находка №2 — деление голоса нужно менить с «индустрия/клиент» на «продажа/техника», по постам

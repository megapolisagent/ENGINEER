# Стоматологическая клиника (соло-кабинет)

Второй реальный прогон `skills/business-teardown`, 2026-08-18. Источник исходных слов: `workspace/2026-08-18-бизнес-стоматологическая-клиника.md`. Владелец — **другой человек, чем в `agentstvo-nedvizhimosti-i-saas.md`** (стоматолог, не Мария); имя не названо — `[УТОЧНИТЬ]`, отдельная запись в `OPEN_QUESTIONS.md`.

## 1. Intake

Существующий бизнес, работает 3 года. Один кабинет: владелец-стоматолог сам ведёт приём + один ассистент + администратор на ресепшене. Поток пациентов органический — сарафанное радио + 2GIS, без платного маркетинга/рекламы (не названо — не заявлялось обратное).

## 2. Outcome Gate — разрыв (зафиксирован до черновика структуры, шаг 2)

«Сейчас непонятно: кого нанимать следующим и какая организационная структура клиники должна появиться, чтобы снять с владельца-стоматолога роль единственного узкого места по времени. После разбора должно быть понятно, какая роль нужна первой и по какому наблюдаемому сигналу — не сам факт наличия схемы ролей.» Подтверждено владельцем дословно, без правок.

## 3. Teardown — четыре вопроса

| Вопрос | Ответ |
|---|---|
| Клиент | В основном терапия и гигиена (кариес, чистки); протезирование не берёт — направляет к знакомому ортопеду. Пациенты преимущественно постоянные, наблюдаются регулярно, не разовые «заболело-пришёл». |
| Отличие/ценность | **Предположение владельца, не факт** — не задерживает приём и не «разводит на лишнее лечение» (жалобы, которые слышал о других клиниках). Сам называет это догадкой: ни разу не спрашивал пациентов напрямую, почему выбрали именно его. Не проверено через прошлое поведение — открытый риск (`SOUL.md`, принцип 4). |
| Активы | Отложено ~3-4 месяца зарплаты одного нового сотрудника (гигиенист или второй врач). Помещение физически вмещает второе кресло, но требует ремонта. Лицензия — на один кабинет; расширение требует переоформления, детали процесса владелец не знает. |
| Веха | `[УТОЧНИТЬ]` — грилинг остановлен владельцем (escape valve, «к синтезу») до ответа. Нет измеримого ориентира «сработало». |

Дополнительно (`Q6`, тоже `[УТОЧНИТЬ]` по escape valve): не проверено, потолок по времени — уже свершившийся факт (отказы пациентам, лист ожидания, регулярные переработки) или пока ощущение «скоро упрусь». Это ключевой пробел — сигнал перехода к найму второго врача (раздел 5 ниже) напрямую зависит от него.

## 4. Внешняя проверка (специалист-агент, узкий бриф + критерий достаточности зафиксирован до вызова)

Вопрос: при упоре соло-практики в потолок по времени — какая практика по **последовательности найма** (гигиенист/ассистент раньше второго врача, или наоборот) и по каким сигналам это решают.

Найдено (источник: Dental Economics — признанное отраслевое издание по practice management, США; частично Henry Schein NDO, ADA — общие критерии ролей):
- Явного правила «сначала гигиенист → потом врач» как прописанной нормы не нашлось; вывод о последовательности — **интерпретация агента-специалиста**, выведенная из экономики: типовое соотношение ~3 гигиениста на 1 полную ставку врача, гигиена даёт быструю, дешёвую окупаемость и обычно делегируется раньше найма ассоциата с полной клинической ставкой.
- Сигналы найма ассоциата (подтверждено источником): устойчивая загрузка расписания 85-90%+ несколько месяцев подряд; производство ≥$25-30 тыс./мес на кресло; запас ≥200-250 неактивных пациентов на каждый рабочий день будущего ассоциата; окупаемость ассоциата обычно занимает 6-12 месяцев.
- Гигиена типично закрывает ~25% времени приёма, которое можно делегировать, и даёт 25-35% выручки практики.
- Косвенный сигнал по листу ожидания: запись на 1-2 месяца вперёд + отказы новым пациентам — по Henry Schein NDO признак готовности к найму ассоциата.

**Явная граница переноса**: источник — американский рынок (доллары, объёмы практики, регуляторика США). Направление логики (делегировать гигиену раньше, чем нанимать второго врача) вероятно переносимо, но **конкретные пороговые цифры — не факт для российского рынка/этой клиники**, помечены как предположение, требуют локальной проверки, не взяты как готовая норма.

## 5. Предложенная функциональная структура

**Фаза 1 — сделать в первую очередь (максимально дешёвый и быстрый рычаг, соответствует активам уже сейчас):**
- **Гигиенист** (или ассистент с квалификацией по гигиене) — принимает на себя чистки/профилактику, снимая эту часть нагрузки с врача. *Обоснование: направление подтверждено внешней практикой (Dental Economics) — гигиена делегируется раньше, чем нанимается второй врач с полной клинической ставкой; финансово соответствует уже имеющимся 3-4 месяцам зарплатного запаса, не требует ремонта/переоформления лицензии, если гигиенист может работать в существующем кабинете по отдельному графику — это предположение, не проверенный факт, `[УТОЧНИТЬ]` у владельца/по регуляторике.*
- Роль администратора/ассистента — без изменений, нет заявленных признаков перегрузки на этом участке.

**Фаза 2 — только после сигнала ниже (требует ремонта + переоформления лицензии — более медленный и дорогой путь, не сейчас):**
- **Второй врач-стоматолог (ассоциат)** — второе кресло. *Обоснование: по найденной практике окупается 6-12 месяцев, требует физического расширения кабинета — не покрывается текущим денежным запасом в одиночку, нужен отдельный финансовый план, `[УТОЧНИТЬ]`.*

## 6. Сигнал перехода фаза 1 → фаза 2

По внешней практике (с поправкой на локальную непроверенность цифр): устойчиво высокая загрузка расписания (ориентир источника — 85-90%+ несколько месяцев подряд) **даже после того, как гигиенист забрал часть нагрузки**, и/или растущий срок ожидания записи с отказами новым пациентам. У владельца этот сигнал сейчас не измерен (`Q6` открыт) — нельзя сказать, близко ли к нему сейчас или далеко.

## 7. Открытые пробелы (не достроено)

- Веха «сработало» (`Q5`) — не названа владельцем.
- Потолок по времени — факт или ощущение (`Q6`) — не подтверждён; без этого нельзя откалибровать, насколько срочна даже фаза 1.
- Отличие/ценность (`Q3`) — предположение владельца, не проверено через пациентов напрямую.
- Может ли гигиенист работать в существующем кабинете по отдельному графику без ремонта/переоформления лицензии, или это тоже требует лицензионных изменений — не проверено, вне текущего v1-контракта (без живых юридических специалистов), только общий флаг.
- Процесс и сроки переоформления лицензии под второй кабинет — не исследовано, юридическая область, вне границ v1 (`DECISIONS.md`, 2026-08-17).
- Цифры внешней практики (загрузка %, суммы, число пациентов) — американский рынок, не подтверждены для локального контекста владельца.
- Имя владельца — не названо, `PROFILE.md` дополнен с пометкой `[УТОЧНИТЬ]`.

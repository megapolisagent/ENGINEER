## Как заполнять

- Новый агент собран → строка в реестр в тот же день, не потом.
- Канон Foundation изменился (что-то попало в `SLUZHEBNYE_FAYLY`/`SLUZHEBNYE_PAPKI`, или отдельное решение вроде deny-правил/installer) → пройти по реестру, обновить колонку «Синхронизирован», для пропущенных — явная причина в этой же колонке, не пустая ячейка.
- Собирается новая специализация с профессиональной методологией (не служебный/чисто софтверный агент) → до финализации характера/способностей запросить у Researcher эталон (`repository-design/SKILL.md`, шаг 1) — колонка «Методология сверена с Researcher» заполняется тогда же, не позже. «Нет» — валидный, но видимый статус, не повод скрывать; повод вернуться и сверить отдельной задачей.
- Появилось новое канонич­еское правило уровня Foundation (как «Стиль письма», 2026-08-26) → пройти по реестру в тот же день, не откладывать на «когда дойдут руки» — для каждого живого агента реально прочитать и проверить, не предположить; колонка заполняется по факту проверки, `[УТОЧНИТЬ]` — валидный статус, если проверка ещё не сделана, но не остаётся пустой ячейкой. Ручная проверка не масштабируется бесконечно — при росте числа агентов эта колонка и есть тот список, по которому проверка идёт систематически, а не по памяти.

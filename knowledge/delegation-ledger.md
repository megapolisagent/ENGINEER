# Delegation Ledger

Реальный, построчный лог каждого запуска другого агента Инженером (`Agent`, headless
`claude -p`, `SendMessage`) — не декларация, а факт: кого вызвали, с каким брифом и
критерием, что получили, каким вердиктом закрыли. Закрывает часть Capability 7
(`dispatching-parallel-agents`/`executing-plans`/`subagent-driven-development`,
`DECISIONS_ARCHIVE.md`, 2026-08-12) — общее место учёта для делегированных вызовов, не
слияние трёх скиллов в один файл и не автоматический review-loop (это остаётся открытым,
см. `DECISIONS.md`, 2026-09-04).

## Формат записи

```
### {дата} — {краткое название}

Цель: {task_id, если создавался, иначе способ вызова}
Целевой агент: {кто}
Бриф: {дословный текст или ссылка на файл с ним}
Критерий достаточности (зафиксирован до вызова): {что считать ответом}
Результат: {факт — коммит/файл/вывод}
Вердикт: OK / FLAG — {почему}
```

## Журнал

### 2026-09-04 — Легальные каналы рыночных данных Avito (Researcher)

Цель: headless `claude -p` из директории Researcher (`AI Intelligence`) — без предварительно
созданного `task_id`; сессия не была открыта для `SendMessage` на момент постановки вопроса
(честно зафиксированный технический пропуск — брифинг ушёл через файл `OPEN_QUESTIONS.md`,
не через прямой вызов с фиксацией `task_id` до старта, как того требует
`instructions/pre-task-check.md` этого дома).
Целевой агент: Researcher (AI Intelligence)
Бриф: `AI Intelligence/OPEN_QUESTIONS.md`, запись «2026-09-04 — Легальные способы получить
рыночные/конкурентные данные Avito для AI Marketing Strategist (не самостоятельный
скрейпинг)» — 4 конкретных пункта (официальный продукт Avito / лицензированные поставщики /
технический тест единичного запроса / метод реальных компаний).
Критерий достаточности (зафиксирован до вызова, дословно из брифа): «по каждому из 4 пунктов
— конкретный найденный факт с источником, включая честное "не найдено"... Итоговый вывод —
не "можно/нельзя" одним словом, а таблица вариантов с ценой и реальным риском каждого».
Результат: все 4 пункта закрыты фактами (официальная «Аналитика спроса» ~4000₽/мес;
bnMAP.pro/наш.дом.рф/IRN.RU/Метриум как лицензированные поставщики; реальный воспроизведённый
`curl`-тест антибот-защиты Avito — 429+капча без заголовков, 200 с полными заголовками;
IRN.RU/Метриум честно раскрывают ручной, не автоматический сбор). Записано в
`AI Intelligence/knowledge/evidence/2026-09-04-avito-market-data-legal-channels-vs-scraping.md`,
коммит `26dcdf4` (уже запушен). Отдельно честно зафиксирован попутный технический сбой —
`mcp__exa__*`/`mcp__firecrawl__*` не работали весь сеанс Researcher (401).
Вердикт: OK — результат покрывает критерий по всем 4 пунктам, включая честные «не найдено»
там, где не нашлось (партнёрский канал к чужим Avito-объявлениям), не выдуманные данные.

# magic-mcp / 21st MCP (21st.dev) — вердикт аудита

Category: decisions_and_constraints

Дата: 2026-09-09

## Что это по факту

`21st-dev/magic-mcp` (бывший «Magic MCP») — открытый тонкий stdio↔HTTPS-прокси (217 строк `src/index.ts`, лично прочитан целиком, ноль runtime-зависимостей) к закрытому облачному сервису `https://21st.dev/api/mcp`. Реальная ценность — каталог 10 000+ React/Tailwind/shadcn-компонентов и AI-генерация UI — целиком на стороне сервера 21st.dev, не в открытом коде. Старое имя пакета (`@21st-dev/magic`) — legacy-прокладка: старые API-ключи уже один раз были сброшены при переезде на «unified 21st MCP».

Поставляется и как Claude Code plugin (`.claude-plugin/` + `skills/21st-ui/SKILL.md`, 48 строк — укладывается в наш потолок 500 строк, в отличие от `graphify/skill.md`, см. [[graphify-verdict]]).

## Модель доступа

Free tier — только поиск по каталогу + 2 установки компонента в день. Платные компоненты отдают код только после разблокировки; режим `generate` (AI-генерация) тратит платные кредиты 21st.dev. Офлайн/self-hosted режима не существует в принципе — сервис по архитектуре closed-source cloud, не просто «по умолчанию с ключом», как у некоторых других аудированных кандидатов.

## Вердикт

Не устанавливать сейчас. Причины:

1. **Нет адресата в текущем составе агентов.** Инструмент строго про фронтенд (React/Tailwind/shadcn/Radix UI). Ни ENGINEER, ни один из известных на сегодня собранных агентов (Marketing Strategist, AI Legal Constructor, math-tutor) не специализируется на фронтенд-сборке — реальной задачи под него сейчас нет. `[УТОЧНИТЬ]`, если в будущем появится агент-фронтендщик — тогда пересмотреть.
2. **Платный облачный сервис по архитектуре**, не опция — та же категория риска, что и у mem0 (внешняя зависимость от чужого API), но без self-hosted пути вообще.

Открытая часть (сам прокси-код) технически чистая — если когда-нибудь в экосистеме появится фронтенд-агент, это резонный Challenger-кандидат для отдельного полноценного PDR, не для повторного аудита с нуля.

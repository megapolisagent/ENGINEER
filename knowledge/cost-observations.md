# Наблюдения по стоимости независимых запусков

## 2026-08-12 — Фиксированная стоимость входа независимого запуска агента

**FACT.** Тривиальный тест (`claude -p "...TEST OK...", --output-format json`, запуск в директории AI Intelligence) стоил **$0.19** при тривиальной задаче (ответить одной строкой, без инструментов). Причина видна в самом ответе харнесса: `cache_creation_input_tokens: 32091` — загрузка полного контекста дома агента (Foundation-файлы, устав) при старте сессии, независимо от размера самой задачи.

Найдено попутно, при проверке механизма Technical Execution Record (`LIFECYCLE.md`, «task_id → session_id → execution trace») — не часть этого механизма, отдельная находка.

## Почему это важно

Независимый запуск агента (не дочерний суб-агент в уже открытой сессии) имеет фиксированную стоимость входа, не зависящую от сложности задачи. Прямой аргумент к более раннему решению об экономии (`DECISIONS.md`, model routing/Resource Efficiency — пока не оформлено постоянным правилом):
- не запускать независимого Reviewer или любого агента без необходимости;
- для рутинных/лёгких проверок — дешёвая модель;
- не тащить полный контекст туда, где задача этого не требует;
- разделять тяжёлые (архитектурные) и лёгкие (рутинные) операции по типу запуска, не только по модели.

## Статус

Открытое наблюдение, не решение. Следующий шаг (не начат) — отдельная инженерная задача про стоимость Engineer/агентов, после Technical Passport.

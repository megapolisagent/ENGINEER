# knowledge/ — открытые развилки

Не факты, не текущее состояние — то, что ещё не решено и ждёт следующего захода. Когда развилка решается (взяли/отклонили окончательно) — строка отсюда убирается; если решение стало устойчивым фактом, ему место в обычной странице `knowledge/`, не здесь.

- **Инструмент:** graphify (Graphify-Labs)
  **Текущий блокер:** тихая самоустановка пакета без спроса, `skill.md` 713 строк (>500 потолок), автовписывание в `CLAUDE.md`, опциональный git-хук — 5 пунктов, ни один не проходит конвейер как есть.
  **Что решить завтра:** появилась ли конкретная задача «разобраться в большом чужом репозитории»; если да — PDR по этим 5 пунктам как чек-листу, не с нуля.

- **Инструмент:** magic-mcp / 21st MCP (21st.dev)
  **Текущий блокер:** платный closed-source облачный сервис без self-hosted пути; в составе нет фронтенд-агента, использовать некому.
  **Что решить завтра:** планируется ли фронтенд-агент; если да — отдельный PDR (открытая прокси-часть технически чистая).

- **Инструмент:** yt-dlp
  **Текущий блокер:** нет самостоятельной задачи — всплыл только как отклонённая video-экстра graphify.
  **Что решить завтра:** нужна ли вообще задача на скачивание/транскрипцию видео; если да — ставить без `--exec`/`--netrc-cmd`, скачанное трактовать как untrusted.

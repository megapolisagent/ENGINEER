# Аудит AI Avitolog (независимая проверка Codex) — 2026-09-02

Секреты (`.env`, `.avito_token_cache.json`) на время аудита вынесены из папки, после — восстановлены.

## 1. Оценка Craft & Behavioral Contract

- Запрет выдумывать данные о состоянии объявлений/баланса прописан явно и многократно
  (`HOME.md`, `SOUL.md`, `SKILL.md`) и подтверждён реальным прогоном на неполных данных
  (2026-08-31) — ни одной выдуманной цифры.
- Одна мелочь: предупреждение о deprecated-эндпоинте в `get_autoload_report_details()`
  печатается в stdout, а не в stderr — риск смешаться с данными в пайплайне.
- **Штампы в автоответе покупателю.** `DEFAULT_AUTOREPLY` в `avito_messenger_client.py` —
  единственный шаблон на все входящие сообщения, не учитывает текст вопроса покупателя.
  Реальный риск: покупателя спросили «можно посмотреть завтра?», а бот отвечает про «полную
  стоимость или ипотеку». WARNING на грани CRITICAL — это уже боевой `--poll-and-reply`, не
  черновик.
- Граница «автоматически / нужно подтверждение владельца» есть только для сообщений
  (трёхступенчатый чек перед авто-ответом). Для автозагрузки фида такой границы нет — при
  замене плейсхолдер-фото на реальные `generate_feed.py` запишет файл без подтверждения, и
  следующий плановый опрос Avito автоматически опубликует все лоты.

## 2. Оценка Tooling

| Операция | Реальный инструмент | Устойчивость |
|---|---|---|
| OAuth2, чтение объявлений/баланса | Официальный HTTP через `urllib` (`avito_api_client.py`) | Токен-кэш есть, retry на сбой — нет, `SystemExit` при ошибке |
| Отчёты автозагрузки | `/autoload/v4/uploads` (актуальный) + `/autoload/v2/reports/*` (**deprecated**) | Без retry, предупреждение о deprecated в stdout |
| Генерация feed.xml | Python-скрипт, локальная запись | Валидация `[УТОЧНИТЬ]` есть, блокировка фото-заглушки есть |
| Авто-ответ покупателю | Официальный HTTP POST (`avito_messenger_client.py`) | **Retry (3 попытки, backoff) + дедупликация — фикс аудита 2026-09-02 на месте, не деградировал** |
| Чтение чатов | Официальный HTTP GET | Без retry |
| Анализ рынка | Python-скрипт + статичный JSON | Не сетевое, валидация входа хорошая |

## 3. Замечания

### CRITICAL
- **`<NewDevelopmentId>` в `generate_feed.py` заполняется текстовым названием ЖК вместо
  числового ID Avito** — почти гарантированно уронит первую реальную загрузку фида для всех
  лотов сразу.
- **Единственный шаблон автоответа** (`DEFAULT_AUTOREPLY`) не учитывает текст сообщения
  покупателя — риск обрыва сделки на первом контакте, уже работает на живых людях.
- **Deprecated Autoload v2 без миграционного плана** — по данным аудита сокращение данных
  начинается 08.09.2026 (**через 6 дней от даты аудита**), полное отключение 08.03.2027;
  в коде только пассивное ожидание «когда Avito добавит», активной задачи на переход нет.

### WARNING
- Сетевые ошибки в `get_items()`/`get_chats()`/`get_token()` не обрабатываются (нет retry,
  необработанное исключение) — только `send_auto_reply()` защищён.
- `market_snapshot_analyzer.py`: константа цены дублирует `knowledge/`-эталон без синхронизации.
- `OPEN_QUESTIONS.md` содержит закрытый по факту вопрос (Messenger API) со статусом «Открыт».
- `avito-integration-spec.md`: URL API помечены `[УТОЧНИТЬ]`, хотя фактически уже известны и
  подтверждены живыми вызовами — документ не синхронизирован с реальностью.
- `README.md` упоминает несуществующую папку `workspace/`; `SKILL.md` ссылается на
  несуществующий файл в `knowledge/evidence/`.

### TRASH
- Пустой тестовый JSON-отчёт в `data/avito_reports/`.
- `scripts/__pycache__/` — не в `.gitignore`.

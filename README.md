# Engineer

Engineer собирает и поддерживает профессиональных AI-агентов. Ниже — как это устроено, простыми словами. Технические детали и статус каждого механизма (что уже работает, что только спроектировано) — в [`LIFECYCLE.md`](LIFECYCLE.md).

## Как это работает

```
                    OWNER
                      │
                      ▼
              Нужен новый агент?
                      │
                      ▼
                 RESEARCHER
          «Как делать эту работу хорошо?»
                      │
                      ▼
                  ENGINEER
             собирает систему
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
    Foundation      Skills      Tools / MCP /
      + Дом                      Plugins
        └─────────────┼─────────────┘
                      ▼
                  AGENT
             работает на деле
                      │
                      ▼
              рабочий отчёт *
                      │
                      ▼
                  ENGINEER
          смотрит и улучшает систему
                      │
              ┌───────┴───────┐
              ▼               ▼
           работает        проблема
              │               │
              ▼               ▼
          продолжаем    исправляем / исследуем
```

\* этот шаг спроектирован, но пока не построен — подробнее в `LIFECYCLE.md`, §9.

## Кто за что отвечает

**Researcher** — исследует, как эта работа профессионально делается в мире. Выдаёт структурированный результат с источниками, не мнение.

**Engineer** — собирает Дом + Foundation + Skills + нужные возможности. Отвечает за то, чтобы агент как техническая система устойчиво выполнял свою задачу — не за то, что у него на месте все файлы.

**Agent** — работает на реальных задачах. Отчитывается о работе в установленном формате (формат уже определён, сам механизм отчёта — впереди).

**Engineer после запуска** — смотрит, как агент работает на практике. Всё хорошо — ничего не трогает. Есть проблема — ищет причину и исправляет: Skill, сам агент, или передаёт вопрос Researcher.

**Skills / Tools / MCP / Plugins** — не ставятся для полноты списка. Engineer ищет, что уже существует → проверяет → подключает то, что нужно → убеждается, что это реально используется, а не просто установлено.

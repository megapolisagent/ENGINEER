# Claude Code Architect & Partner (Engineer)

Главный инженер агентных систем и хранитель библиотеки **Skill System**.
Отвечает за архитектуру, устойчивость и качество работы агентов экосистемы на базе каркаса Foundation без раздувания контекста и деградации памяти.

## Принципы работы

- **Lean Core:** чистая архитектура без лишних надстроек (`CLAUDE.md`, `.claude/rules/`, `.claude/skills/`).
- **Skill System:** хранение переиспользуемых инструментов по стандарту Progressive Disclosure (ядро до 500 строк).
- **TDD для навыков:** разработка навыков строго через RED/GREEN/REFACTOR цикл (скилл `skill-authoring`).
- **Adopt before Build:** проверка существующих готовых решений перед разработкой с нуля.
- **Evidence-based:** завершение задач только при наличии свежих фактических доказательств работы (`verification-before-completion`).

## Структура репозитория

```text
.
├── CLAUDE.md                  # Главный системный контракт и инварианты роли
├── .claude/
│   ├── rules/                 # Постоянные поведенческие правила
│   └── skills/                # Исполняемые навыки по требованию
│       └── skill-authoring/   # Создание и TDD-валидация скиллов
└── README.md                  # Описание репозитория
```

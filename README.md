# Engineer

Engineer отвечает за то, чтобы агент как техническая система устойчиво достигал требуемого профессионального результата — не просто был собран.

## Как работает

```
Нужен профессиональный агент
        ↓
Engineer понимает задачу
и проверяет, достаточно ли входа
        ↓
Researcher → как выглядит хорошая
профессиональная работа
        ↓
Engineer собирает агента
из Дома + нужных способностей
и технических возможностей
        ↓
проверяет, что агент технически готов к работе
        ↓
агент работает на реальной задаче
        ↓
Engineer смотрит на результат
        ↓
работает хорошо → оставляет
есть проблема → находит причину → исправляет
        ↓
готовый профессиональный агент
```

Сейчас часть последующего цикла ещё строится; актуальный статус механизмов — в `LIFECYCLE.md`.

## Что получает владелец

Агента, чей результат проверен, а не просто «все файлы на месте».

## Вход

Вы называете задачу. Engineer сам определяет, достаточно ли информации, чтобы понять требуемый результат.

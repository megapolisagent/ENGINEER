# Правка: избыточный `cd` перед git-командами вызывал permission prompt

Дата: 2026-08-12

Было: весь день добавляла `cd "путь/к/ENGINEER" &&` перед каждой git-командой по привычке, хотя рабочая директория уже была верной (сохраняется между командами Bash-инструмента). Составная команда `cd <путь> && git ...` сама провоцирует запрос подтверждения у владельца — даже когда переход ничего не меняет.

Правильно: перед git (и любой другой) командой не добавлять `cd` без причины — рабочая директория persists, проверить `pwd`, если сомневаешься, а не добавлять `cd` «на всякий случай». Причина не в permissions-конфигурации, а в выборе формы команды.
